## Product tension

- **Old framing:** chore / workload equality between partners.
- **New framing (this request):** shared purchase needs + voluntary whereabouts (where / when back), never forced location.

V1 must pick a primary job.

## Working definition (draft)

A web app for a small household to answer:

1. What do we need to buy?
2. Who is out, where, and when back — **only if they chose to share?**

Privacy: presence is author-controlled; no GPS; no required ETA.

## Proposed V1 surfaces (pending answers)

1. **Today** — urgent buys + people currently out (shared notes only)
2. **Needs** — add / claim / bought / remove
3. **Presence** — optional place label + expected back; clear/update
4. **Household** — invite, roles, privacy defaults

Out of V1 unless insisted: chores, gamification, GPS/maps, chat, clinical care.
